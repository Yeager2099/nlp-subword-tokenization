# Subword Tokenization and Text Normalization

**Course:** CIS 5300 / HW2  
**Artifact type:** Course project / coursework

## Overview

Implemented byte-pair encoding and preprocessing utilities for tokenization, stemming, and lemmatization. Compared custom tokenizers with NLTK and tiktoken and considered morphology and multilingual text.

## Guiding question

How do normalization and subword segmentation affect vocabulary and tokenization behavior?

## Methods and technical scope

Python; BPE; NLTK; tiktoken.

## Evaluation and analysis

Compare vocabulary size and segmentations across normalization choices and languages. Exact tokenizer behavior depends on library and model versions.
